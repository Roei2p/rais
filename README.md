# הכסף שלי

אפליקציה פשוטה לדעת כמה כסף נשאר עד סוף החודש, וכמה אפשר להוציא היום בלי להיכנס למינוס.

- רושמים פעם אחת מה נכנס ומה משלמים קבוע כל חודש
- רושמים הוצאות בלחיצה
- רואים כמה מותר להוציא היום, על מה הלך הכסף, ויעדי חיסכון

בלי הרשמה ובלי חיבור לבנק – הנתונים נשמרים רק בדפדפן של המשתמש.

**כתובת:** https://roei2p.github.io/rais/

## פיתוח

```bash
npm install
npm run dev
```

כל דחיפה ל־`main` בונה ומעלה את האתר אוטומטית ל־GitHub Pages.
